# 이메일 템플릿 자동 생성기 (Email Template Builder)

이미지와 링크만 있으면 이메일 템플릿(HTML)을 자동으로 생성하고 Github에 배포해주는 로컬 자동화 툴입니다.

## 주요 기능
- **이미지 자동 리사이징**: 원본 이미지를 자동으로 가로 1000px에 맞게 최적화합니다.
- **버튼 위치 자동 탐색 (템플릿 매칭)**: 전체 이미지 내에서 버튼 이미지를 스캔하여 클릭 좌표를 스스로 계산합니다.
- **2가지 레이아웃 포맷 지원**:
  1. **모바일 용도 (반응형)**: 화면 크기에 맞춰 조절되며 이미지 전체가 클릭 영역이 됩니다.
  2. **이메일 용도 (고정폭)**: 가로 1000px로 고정되며, `usemap`을 사용하여 지정된 버튼 영역만 클릭되도록 설정합니다.
- **원클릭 배포 (Git Push)**: 로컬 Git 설정을 활용하여 클릭 한 번으로 Github에 자동 푸시 및 배포됩니다.

## 🚀 사용 방법

### 1. 로컬 서버 실행 (필수)
브라우저에서 직접 Github API로 전송 시 발생할 수 있는 보안 문제(토큰 권한, CORS 이슈)를 방지하기 위해 로컬 API 서버(`server.py`)를 가동해야 합니다.

터미널이나 명령 프롬프트(cmd)를 열고 다음 명령어를 실행하세요:
```bash
python server.py
```
*(실행 후 `http://127.0.0.1:5000` 주소로 로컬 서버가 시작됩니다.)*

### 2. 브라우저 접속
웹 브라우저를 열고 다음 주소로 접속합니다:
👉 **[http://127.0.0.1:5000](http://127.0.0.1:5000)**

### 3. 설정 입력 및 배포
1. **기본 설정**: 생성될 **파일명**(예: `email_260601`)과 클릭 시 이동할 **타겟 URL**을 입력합니다.
2. **포맷 선택**: 용도에 맞는 레이아웃을 선택합니다 (모바일 반응형 vs 고정폭 이미지맵).
3. **이미지 업로드**: `원본 전체 이미지`를 업로드합니다. 고정폭 용도를 선택한 경우 `버튼 전용 이미지`도 함께 업로드합니다.
4. **HTML 생성 및 매칭**: [HTML 생성 및 매칭하기] 버튼을 누르면 내부 비전 엔진이 버튼 위치를 탐색하고 코드를 생성합니다. 우측에서 결과를 눈으로 확인할 수 있습니다.
5. **Github 배포**: [Github 배포하기] 버튼을 누르면 레포지토리로 반영되며, 최종적으로 웹에 접속 가능한 URL 링크가 표시됩니다.

## 🔒 보안 검토 완료 안내
- **Git Token 완벽 제거**: 본 프로그램 내(UI 스크립트 및 서버 파이썬 스크립트 등 모든 파일)에는 Github Token(PAT) 문자열이나 이를 로컬스토리지에 저장하는 로직이 **전혀 남아있지 않습니다.** 보안 취약점 점검을 통해 모두 깨끗하게 삭제되었습니다.
- **시스템 권한 사용**: Github 배포 기능은 사용자의 컴퓨터에 이미 안전하게 설정되어 있는 시스템 내장 Git 자격 증명(Credential Helper)을 그대로 차용합니다. 따라서 외부 인증 정보 유출 위험 없이 100% 안전하게 동작합니다.
